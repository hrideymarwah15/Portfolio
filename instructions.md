# AGENT INSTRUCTIONS

## Purpose
This project is a professional portfolio website.
The primary objective is to communicate clarity, competence, and trust to recruiters
through excellent UI/UX and correct, reliable functionality.

Visual quality and interaction quality matter more than adding features.

---

## Priority Order (Non-Negotiable)

1. UI clarity and visual restraint
2. UX flow and cognitive ease
3. Functional correctness
4. Code cleanliness
5. Feature completeness

If a decision improves code but harms UI/UX, reject it.

---

## UI / UX PRINCIPLES

### Design Philosophy
- Calm, minimal, enterprise-grade aesthetic
- Dark theme by default
- Serious, professional tone
- No visual noise
- No attention-seeking elements

Design should feel inevitable, not impressive.

---

### Layout Rules
- Generous spacing
- Clear visual hierarchy
- One primary idea per section
- No clutter or decorative elements

Never add an element unless it serves clarity.

---

### Color & Typography
- Near-black background
- Off-white text only
- One muted accent color maximum
- Single sans-serif font (Inter)

If a color or font draws attention to itself, remove it.

---

### Motion & Interaction
- Subtle fade-ins only
- No parallax
- No scroll hijacking
- No unnecessary hover effects

Motion must support comprehension, not entertainment.

---

## UX FLOW RULES

- Recruiter should understand value within 30 seconds
- Navigation must be obvious without explanation
- Scrolling should feel natural and uninterrupted
- Clicks should always lead somewhere meaningful

Never force exploration.

---

## FUNCTIONALITY REQUIREMENTS

- All links must work
- Navigation must be predictable
- No broken states
- No dead UI elements
- Responsive behavior must preserve hierarchy

If functionality is uncertain, simplify.

---

## CODE STANDARDS

- Prefer clarity over cleverness
- Use semantic HTML
- Avoid unnecessary abstractions
- Components must be small and readable
- Tailwind classes must remain legible

Readable code is a UX feature.

---

## FEATURE DISCIPLINE

DO NOT add:
- Animations for decoration
- Extra sections without purpose
- Experimental UI patterns
- Marketing elements
- Trend-driven design

Every feature must earn its place.

---

## COPY & CONTENT RULES

- Short sentences
- Declarative tone
- No buzzwords
- No emotional language
- No self-praise

Let structure and clarity speak.

---

## QUALITY CHECKLIST (Before Every Commit)

- Does this improve clarity?
- Does this reduce cognitive load?
- Does this make the page calmer?
- Does this make intent clearer?
- Would a recruiter trust this?

If any answer is “no”, revise.

---

## Final Rule

This is not a playground.
This is a professional signal.

Build less.
Refine more.
